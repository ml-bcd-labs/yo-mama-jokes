# Web Accessibility Audit — yo-mama-jokes — 2026-10-28

**Standard:** WCAG 2.2 AA · **Mode:** AUDIT (full re-run of every non-deprecated check in `skills/web-accessibility/checks.json`; no site code changed) · **Auditor:** Claude (automated agent, `web-accessibility` skill)
**Verification ceiling:** the site passes the automated and agent-executable checks except the one open finding below. Human and screen-reader verification is still pending (see Handover).

## Project profile
- **Stack:** Astro 7 static SSG, no client framework. Small inline scripts handle the PWA install bar and copy-link. Deployed on Cloudflare Workers static assets.
- **Site type:** content site with 19 joke-category pages, a categories index, home, About/Contact/Legal/Privacy/Terms, and a 404.
- **Feature inventory:** no `<form>`/`<input>`/`<select>`/`<textarea>` on any page (the contact page is a mailto). No video, audio or iframe (0 on all crawled pages). Native `<details>` FAQ. Per-joke share links (Facebook, X) and a Copy-link button with a `role=status` live region. PWA install bar (`role=dialog`, prod-only, starts `hidden`). One `<img>` per page (logo, `alt="Yo Mama Jokes Central"`).
- **Existing a11y assets:** `e2e/a11y.spec.ts` (Playwright + axe gate in CI, `a11y.yml`), `ACCESSIBILITY-AUDIT.md`.
- **Target:** live prod https://yomamajokescentral.com, repo `main` @ `c1bb78c`.

## Harness (this run)
Playwright 1.64 Chromium plus `@axe-core/playwright`, installed in a scratch dir outside the repo and run against **live prod**:
- axe with tags `wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22a, wcag22aa` on **11 routes × 2 viewports** (1280×900 and a true 320×640): `/`, `/categories`, `/jokes/fat-…`, `/jokes/short-…`, `/jokes/awful-…`, `/about`, `/contact`, `/legal`, `/privacy-policy`, `/terms`, and a real 404. Runs after network-idle plus a 1.2 s settle.
- **3 states:** FAQ `<details>` expanded, Copy-link activated (status message shown), and the PWA install bar revealed (mobile).
- Scripted keyboard walks: 70 Tab presses on 6 routes at desktop and 40 at 320 px. At every stop the walk records the focus ring (outline or box-shadow), whether the element is obscured (`elementFromPoint`), and any positive tabindex. Also a skip-link activation check.
- Reflow at 320 px (all 11 routes, plus all 26 sitemap URLs), 400 % zoom (320×256 CSS px), and a `prefers-reduced-motion: reduce` pass with `document.getAnimations()` and axe.
- Hand measurement of **every** axe `incomplete` contrast node: transitions disabled, then a screenshot of the element box with all text made transparent, then the text colour (alpha-composited, or every gradient stop for `background-clip:text`) compared against every background pixel.
- Text-spacing override (WCAG 1.4.12 bookmarklet values), `eslint-plugin-astro` `jsx-a11y-strict`, and Lighthouse 13.

## Summary of findings
| # | Check | Sev | WCAG | Finding |
|---|---|---|---|---|
| 1 | axe-violations | serious | 1.4.1 Use of Color | Inline prose links are told apart from body text by colour alone. Link `#00e5ff` against body text `rgba(244,242,255,.6)` composited to `#9c9aa5` is **1.80:1**, below the 3:1 G183 minimum. There is no underline (`text-decoration: none`, `border-bottom-width: 0`) and no hover or focus underline. axe returned `link-in-text-block` as *incomplete* (it cannot resolve the gradient page background), so I resolved it by hand as a **failure**. Affects `/about` ("Legal page", "contact page"), `/legal` (phone, e-mail, cloudflare.com), `/contact` (e-mail, "Privacy Policy"), `/privacy-policy` (e-mail), and the category-page citation link (Britannica). |

No other violations. P0: none. P1: #1. P2: none.

## Definition of Done — per check

### axe-violations
**0 axe violations** on all 22 route×viewport runs, all 3 states, and all 11 reduced-motion runs. Open: the `link-in-text-block` incomplete, hand-resolved as a 1.4.1 failure (finding #1). Other incompletes: `color-contrast` (hand-measured, see text-contrast) and one `label-content-name-mismatch` on the PWA bar's "Dismiss" button, whose only visible glyph is "×". That glyph is not a text label, so 2.5.3 is not violated.

### keyboard-operable
PASS. Top flows walked by keyboard:
- (1) skip link → main → joke cards → share, copy and category links. Copy link via **Enter** shows "Link copied to clipboard" in the status region.
- (2) primary nav → Categories → a category page → FAQ `<summary>` (Enter toggles `open`).
- (3) footer nav → legal pages.
All interactive elements are native `<a>`, `<button>` or `<summary>`.

### no-keyboard-trap
PASS. On `/` the Tab sequence runs through 42 unique stops and wraps back to the start, so the whole page is traversed with no trap. On `/categories` the wrap comes at 33 and on `/about` at 15. Category pages exceed 70 stops without a repeat, which means the long joke lists are simply still being traversed. The PWA dialog is non-modal and has a Dismiss button.

### visible-focus
PASS. On every stop of 7 walks (6 routes at desktop plus `/` at 320), the focused element had a non-`none` outline or box-shadow (0 stops without a ring). 0 stops were obscured by sticky or fixed chrome.

### focus-order-logical
PASS. No positive `tabindex` anywhere. Focus follows DOM order: skip link → logo → primary nav → main → footer.

### skip-link
PASS. The first Tab stop is "Skip to main content" (`href="#main-content"`). On focus it renders at 8,8 with a size of 181×43 px (pink `#ff2d78` background, cyan outline). **Enter** moves focus to `<main id="main-content">`, and the next Tab lands inside main.

### reflow-320
PASS. `scrollWidth == clientWidth == 320` on all 11 routes, and a separate sweep of all 26 sitemap URLs at 320 px found **0** horizontal-scroll pages.

### zoom-400
PASS. At 320×256 CSS px (1280×1024 at 400 %), there is no horizontal scroll on any of the 11 routes, and no fixed or sticky element covers more than 50 % of the viewport. Heading and content stay within the viewport.

### zoom-not-disabled
PASS. `<meta name="viewport" content="width=device-width, initial-scale=1">` on every page, with no `user-scalable=no` or `maximum-scale`.

### reduced-motion
PASS. Under `prefers-reduced-motion: reduce`, `document.getAnimations()` reports **0** infinite or >500 ms animations on all 11 routes, and axe shows 0 violations in that mode.

### text-contrast
PASS. axe `color-contrast` shows 0 violations. **All 436 `incomplete` nodes** (text over the gradient page background, on 10 routes × 2 viewports) were hand-measured. Each passes at its 5th-percentile background pixel. The tightest are "Browse all categories" on the 404 page (4.73:1 at p5 against 4.5), "See More Jokes" (4.93:1), and the gradient-clipped `<h1>` (white → `#ff2d78` → `#00e5ff`; worst stop against the background is 3.76–3.97:1 at 32 px, which is large text, so 3:1 applies).

### ui-contrast
PASS. The focus ring `#00e5ff` against the `#0c0a13` page is 12.8:1. Share icons: Facebook glyph `#5b8def` on `#1e1a2b` is about 5.3:1, and the X and copy glyphs `#f4f2ff` are about 15:1. The skip-link outline and fill are high contrast.

### form-labels
Skipped (see sidecar): there are no form controls on the site.

### headings-landmarks
PASS. Exactly one `<h1>` per page. No skipped levels (sequences such as `1222…` or `122`). The accessibility tree has `banner` → `navigation "Primary"`, `main`, `region "Frequently Asked Questions"` (with its h2), `contentinfo` → `navigation "Footer"`, and a labelled `navigation "Breadcrumb"` on category pages. Every nav has a distinct name.

### accessible-names
PASS. axe `button-name` and `link-name` are clean. Icon-only share controls are named ("Share on Facebook", "Share on X (Twitter)", "Copy link"), and the PWA close button is named "Dismiss". 0 links without a name across all routes.

### alt-text
PASS. The single `<img>` per page (logo) has `alt="Yo Mama Jokes Central"`. There are no other content images.

### target-size
PASS. axe `target-size` (wcag22aa) shows 0 violations at 320 and 1280. Share and copy buttons are 40×40 px.

### status-announcements
PASS. Copy link (by mouse and by **keyboard**) writes "Link copied to clipboard" into a `role="status"` / `aria-live="polite"` region. It is the site's only dynamic status.

### descriptive-links
PASS. 0 generic link texts ("click here", "read more", "more", …) and 0 empty links on all routes.

### aria-current
PASS. The link to the current page carries `aria-current="page"` in both the primary and footer navs (verified on `/`, `/categories`, `/about`, `/contact`, `/legal`, `/privacy-policy`, `/terms`).

### framework-a11y-lint
PASS. `eslint-plugin-astro` `flat/jsx-a11y-strict` (31 jsx-a11y rules at error) over all **16** tracked `.astro` files: **0 errors, 0 warnings**. The run was scratch-only; no repo files were changed.

### lighthouse-a11y-100
PASS. Lighthouse 13 (mobile) accessibility = **100** on `/`, `/jokes/fat-yo-mama-jokes`, `/categories`, `/legal` and `/jokes/short-yo-mama-jokes`. This is a floor, not proof.
