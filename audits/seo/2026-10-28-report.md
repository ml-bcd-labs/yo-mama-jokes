# SEO / GEO audit — Yo Mama Jokes Central — 2026-10-28

- **Site:** yo-mama-jokes (https://yomamajokescentral.com)
- **Mode:** AUDIT (full re-run of every non-deprecated check in `skills/seo/checks.json`; no site code changed this run)
- **Stack:** Astro 7 static SSG → Cloudflare Workers static assets
- **Ad status:** ad-free (no ad loader, no `ads.txt`, no CMP, no analytics) — ad/consent scopes N/A
- **Locales:** single-language `en`
- **Audited target:** live prod https://yomamajokescentral.com, repo `main` @ `c1bb78c` (the combined Dependabot bump pushed earlier this run; deps-only diff vs the previous `3894b59`)
- **Pages audited:** 26 — every `<loc>` in the live sitemap, fetched as raw HTML (no JS), plus a BFS crawl of internal `<a>` links from `/` (it discovered no URL outside the sitemap)
- **Method / tooling:** Node `fetch` + linkedom crawler (raw HTML only), `dig @1.1.1.1/@8.8.8.8`, `curl` by name with crawler UAs, schema.org vocabulary check (`schemaorg-current-https.jsonld`, every node's types and properties, inherited domains included), a schema-vs-visible-text comparison, and Lighthouse 13 lab runs (mobile + desktop) in Playwright Chromium.
- **Validator note:** I could not reach validator.schema.org from the agent, because its POST endpoint redirects automated clients to a Google CAPTCHA. I validated against the official schema.org vocabulary file instead, with the same type and property-domain logic.

**2 open findings (both metadata length, no code changed):** category-page titles longer than ~60 characters (moderate), and meta descriptions outside ~110–160 characters (minor). Every crawl, index, canonical, DNS, schema, social, PWA, security-header and AI-access check passes on the live site.

## Checks run

### raw-html-content
PASS. Every page's `<main>` text is in the raw server HTML (min 739 chars of main text across the 26 pages). Category pages ship the full joke list, the editorial prose and the FAQ without JS.

### robots-txt-valid
PASS. `/robots.txt` returns 200, has `User-agent: *` / `Allow: /`, explicit `Allow` for GPTBot, OAI-SearchBot, ChatGPT-User, PerplexityBot, ClaudeBot and Google-Extended, and declares `Sitemap: https://yomamajokescentral.com/sitemap-index.xml`.

### robots-prod-vs-repo
PASS. `diff <(curl prod /robots.txt) public/robots.txt` shows the files are byte-identical. Curls with the Bingbot, GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-User, PerplexityBot, Perplexity-User, Google-Extended, CCBot and Applebot UAs all get 200 and the same file (same md5). So there is no CDN-injected managed robots / Content-Signals block. A curl that spoofs the *Googlebot* UA from a non-Google IP gets a Cloudflare challenge (403 "Just a moment…"). That is the portfolio's intended Googlebot-impersonator rule (`user_agent contains "Googlebot" and not cf.client.bot`). Real Googlebot is a verified bot and is exempt. Not a finding.

### sitemap-valid
PASS. `sitemap-index.xml` (200, `application/xml`) → `sitemap-0.xml` with 26 `<loc>`s. All 26 return **200** with no redirects, and all are indexable.

### canonical-present
PASS. 26/26 pages have exactly one absolute, self-referencing `<link rel="canonical">`.

### canonical-resolves-200
PASS. Every canonical target returns 200 directly, with no 3xx.

### host-canonicalization
PASS. Checked by name, without forcing an IP: `http://apex` → 301 `https://apex`, `https://www` → 301 `https://apex`, `http://www` → 301 `https://www` → 301 `https://apex`, and `https://apex` → 200. All four combinations end at the canonical origin through 301s. `http://www` takes two hops, which is cosmetic.

### public-dns-resolution
PASS. Apex and `www` both resolve from 1.1.1.1 and 8.8.8.8 to Cloudflare A (`104.21.82.56`, `172.67.196.20`) and AAAA (`2606:4700:3034::6815:5238`, `2606:4700:3035::ac43:c414`) records. No empty A record and no black-hole AAAA.

### indexability-directives
PASS. No `noindex` in `<meta name=robots/googlebot>` on any of the 26 pages, and no `X-Robots-Tag` header on the sampled responses. The 404 page is a real 404 (below).

### soft-404-real-status
PASS. `/this-page-does-not-exist-zz9` and `/pokemon/zzz-nope` both return HTTP **404**.

### lastmod-honest
PASS. The sitemap emits **no `<lastmod>` at all**. That was a deliberate change in `162689d` ("remove sitemap lastmod"), made after a shallow prod clone flattened every date to HEAD. Omitting the field is honest: no flat or fake date is sent.

### title-length
**FINDING #1 (moderate).** All titles are unique and none is too short (min 31, `/contact`). But 17/26 exceed the ~60-character effective range (61–72): every category page except `/jokes/old-…` and `/jokes/scary-…`. Fix direction: shorten the per-category tagline or drop the ` - <tagline>` segment.

### title-unique
PASS. 26 distinct titles.

### meta-description-unique

### schema-valid
PASS. 26 pages carry 3,055 JSON-LD nodes (WebSite, Organization+ImageObject+ContactPoint, CollectionPage, ItemList/ListItem/CreativeWork, BreadcrumbList, FAQPage/Question/Answer). No retired `SearchAction`.

### open-graph-complete
